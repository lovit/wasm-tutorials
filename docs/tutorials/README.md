## 아직 쓰는 중이다

문서는 예제보다 뒤에 쓴다. 예제로 직접 확인하기 전에 쓰면 추측을 사실처럼 적게 되기 때문이다. 예를 들어 03번의 "부팅에 몇 초 걸리나" 는 01번 예제가 실제로 재고 나서 적는 편이 정확하다. 목차에 링크가 없는 것은 아직 쓰기 전이라는 뜻이고, 쓰는 대로 링크가 붙는다. 진행 상황은 [이슈 목록](https://github.com/lovit/wasm-tutorials/issues?q=is%3Aissue+label%3Adocs)에서 볼 수 있다.
